# jwleesnu.github.io

Personal homepage of Jaewoo Lee (이재우), Ph.D. student in Aerospace Engineering at Seoul National University ([LARR](http://larr.snu.ac.kr)).

**Live:** https://jwleesnu.github.io/

A static page with no build step: `index.html` + `styles.css` + `script.js` + `assets/`. `.nojekyll` tells GitHub Pages to serve the files as they are.

Preview locally with `python3 -m http.server` in this folder, then open http://localhost:8000/.
